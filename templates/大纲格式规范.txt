# ============================================================
# 大纲格式规范 v1.0
# 整个故事的宏观规划，不是每章的细节
# ============================================================

# ════════════════════════════════════════════════════════════
#  一、大纲 vs 细纲的区别
# ════════════════════════════════════════════════════════════

大纲（本规范）：
  - 整个故事的宏观规划
  - 每卷的核心目标和转折
  - 主角的成长弧线
  - 主要伏笔的布局
  - 不涉及具体章节细节

细纲（另一份规范）：
  - 每章的具体内容
  - 每章的场景安排
  - 每章的爽点设计
  - 每章的生成prompt

简单说：
  大纲 = 这个故事要讲什么
  细纲 = 这一章要写什么

# ════════════════════════════════════════════════════════════
#  二、字段分级
# ════════════════════════════════════════════════════════════

## Tier1 基础性（绝对不可偏离）

  title                 故事标题
  genre                 类型（玄幻/都市/修仙/etc）
  total_volumes         总卷数
  total_chapters        总章数
  core_theme            核心主题（一句话）
  protagonist           主角名称
  protagonist_goal      主角的终极目标
  golden_finger         金手指/系统设定
  world_setting         世界观设定
  power_system          力量体系
  ending                结局走向

## Tier2 可演变（随剧情自然变化）

  volumes               各卷规划（数组）
    - volume_number:    卷号
      volume_title:     卷标题
      chapter_range:    章节范围
      core_conflict:    核心冲突
      core_goal:        本卷目标
      key_events:       关键事件
      new_characters:   新增角色
      new_locations:    新增地点
      foreshadows:      本卷伏笔
      satisfaction:     本卷爽点

  main_plot_lines       主线剧情（数组）
  sub_plot_lines        支线剧情（数组）

## Tier3 可偏离（根据行文情况调整）

  notes                 备注
  style_notes           风格说明

#  三、字段说明

## 基础信息
- title:              故事标题
- genre:              类型
- total_volumes:      总卷数
- total_chapters:     总章数
- core_theme:         核心主题（一句话）
- protagonist:        主角名称
- protagonist_goal:   主角的终极目标
- golden_finger:      金手指/系统设定
- world_setting:      世界观设定
- power_system:       力量体系
- ending:             结局走向

## 卷级规划
- volumes:            各卷规划（数组）
  - volume_number:    卷号
    volume_title:     卷标题
    chapter_range:    章节范围（chXXX-chXXX）
    core_conflict:    核心冲突（一句话）
    core_goal:        本卷目标（一句话）
    key_events:       关键事件（数组）
    new_characters:   新增角色（数组）
    new_locations:    新增地点（数组）
    foreshadows:      本卷伏笔（数组）
    satisfaction:     本卷爽点（数组）

## 剧情线
- main_plot_lines:    主线剧情（数组）
- sub_plot_lines:     支线剧情（数组）

## 元信息
- notes:              备注
- style_notes:        风格说明

# ════════════════════════════════════════════════════════════
#  五、与其他系统的关联
# ════════════════════════════════════════════════════════════

1. 细纲
   - 大纲的 volumes → 细纲的卷级规划
   - 大纲的 key_events → 细纲的章节安排

2. 角色档案
   - 大纲的 protagonist → 角色档案的 name
   - 大纲的 new_characters → 角色档案的 first_appearance

3. 地点档案
   - 大纲的 new_locations → 地点档案的 first_appearance

4. 伏笔系统
   - 大纲的 foreshadows → 伏笔的引入章节

5. 时间线
   - 大纲的 volumes → 时间线的章节范围
   - 大纲的 key_events → 时间线的关键节点

6. 上下文引擎
   - 大纲的当前卷信息 → 注入prompt
   - 帮助LLM理解故事走向
