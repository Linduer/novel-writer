# ============================================================
# 角色档案格式规范 v2.0
# 所有角色必须按此格式填写，字段不可省略
# ============================================================

# ════════════════════════════════════════════════════════════
#  一、字段分级（对应三级约束体系）
# ════════════════════════════════════════════════════════════

所有字段按"可变性"分为三档，冲突时高档优先。

## 第一档：基础性（绝对不可偏离）— Tier1

一旦写定永远不改，写入 Tier1 基础约束。

  name                    角色名
  role_type               角色类型
  identity                核心身份
  origin                  出身来历
  personality             性格底色（底层人格，不是情绪状态）
  abilities.天赋          天赋类型（innate，不可后天获得）
  abilities.境界上限      能力天花板（写死）
  constraints             硬规则
  signature_items         标志性物件（反复出场）
  appearance.memorable_detail  独特外貌细节（标志性特征）
  equipment.特殊          特殊装备（绑定角色）

## 第二档：可演变（随行文自然变化）— Tier2

会随剧情发展而变化，在 growth_arc 中分阶段记录。

  appearance.age          年龄（写范围，不写死数字）
  appearance.build        体型（受伤/锻炼后变化）
  appearance.signature    外观变化（换装备/留疤）
  emotional_baseline      情绪基线随经历改变
  catchphrases            口头禅会演变
  abilities.境界          实际境界提升（abilities.json追踪）
  abilities.战斗方式      战斗方式随能力变化
  abilities.特殊能力      特殊能力（后天获得的）
  equipment.*             装备变化（换武器/升级装备）
  inventory.消耗品       消耗品数量变化
  inventory.关键物品     关键物品获取/失去
  key_relationships       关系类型变化
  secrets                 秘密可能被揭晓
  status                  在世状态（active→dead）
  exit_chapter            下线章节（退场/离开/死亡）
  exit_type               退场类型（dead/retired/banished等）
  return_chapter          回归章节（临时下线后回来）
  growth_arc              成长弧线本身

## 第三档：可偏离（根据行文情况调整）— Tier3

每章可灵活调整，写完归档，下次覆盖。

  appearance.具体描写     同一个"偏瘦"，每章描述方式不同
  speaking_style.细节     同样报价式吐槽，具体台词每章不同
  role_function           核心功能不变，每章具体作用可微调
  personality_arc         总方向不变，措辞可调整
  inventory.消耗品.数量  消耗品具体数量每章可变


# ════════════════════════════════════════════════════════════
#  全局ID标准（所有规范通用）
# ════════════════════════════════════════════════════════════

所有规范必须遵守以下ID格式：

| ID类型 | 格式 | 示例 | 说明 |
|--------|------|------|------|
| 章节ID | chNNNN | ch0001, ch0095, ch0838 | 四位数字，补零 |
| 场景ID | chNNNN_SNN | ch0095_S01 | 章节+下划线+两位序号 |
| 伏笔ID | fsNNN | fs001, fs010, fs022 | 三位数字，补零 |
| 时间点ID | tNNNN | t0001, t0095 | 四位数字，补零 |

注意：
  - 章节ID必须用四位数字（ch0001，不是ch001）
  - 范围用连字符：ch0001-ch0096
  - 伏笔引入/回收章节必须用chNNNN格式，不能用自然语言（如"卷一闲笔"）
  - 已有数据中的3位格式（ch001）视为向后兼容，新数据必须用4位


# ════════════════════════════════════════════════════════════
#  二、字段说明
# ════════════════════════════════════════════════════════════

## 基础信息
- name:             角色名（唯一标识，不可重复）
- role_type:        角色类型（见取值表）
- role_function:    角色功能（一句话说明这个角色在故事里干什么）

## 身份与背景
- identity:         一句话身份概括（50字以内）
- origin:           出身/来历（详细背景，100-200字）

## 外貌特征
- appearance:
    age:              年龄（写范围如"二十五六岁"，不写死数字）
    age_note:         年龄变化说明（可选，标注重大变化的章节节点）
    build:            体型
    signature:        标志性外观（一眼能认出的特征）
    memorable_detail: 独特细节（便于读者记忆的点）

## 性格
- personality:          核心性格（2-4个关键词+一句话描述）
- emotional_baseline:   默认情绪状态（不触发事件时是什么状态）
- personality_arc:      性格变化方向（从A到B的一句话描述）

## 说话风格
- speaking_style:   说话风格描述（一句话）
- catchphrases:     高频词/口头禅（3-5个，数组格式）

## 能力（静态设计）
- abilities:
    天赋:         天赋类型和效果（innate，Tier1不可变）
    境界上限:     这个角色能达到的最高境界（天花板）
    特殊能力:     后天获得的能力（acquired）
    战斗方式:     怎么打架（不写战斗的角色写"不参战"）
    能力成长:     能力随剧情变化的说明（与growth_arc配合）

## 装备（静态设计）
- equipment:
    主手:         主要武器/工具
    副手:         副武器/盾牌
    防具:         防护装备
    饰品:         饰品/挂件（1-2个）
    特殊:         特殊装备（如乐园的设施权限）

## 物品（静态设计）
- inventory:
    固定物品:     一直持有的物品（与signature_items配合）
    消耗品:       可消耗的物品（药水/弹药等）
    关键物品:     推动剧情的重要物品（标注获取/失去章节）

## 能力状态（动态，与abilities.json绑定）
- ability_state:
    文件位置:     data/{项目名}/memory/abilities.json
    更新方式:     每章写完后自动更新
    查询命令:     python main.py abilities --character [角色名]
    说明:         此字段不在档案中填写，由系统自动维护

## 出场规划
- appearances:
    first_chapter:   首次出场章节（chNNNN格式）
    last_chapter:    最后出场章节（chNNNN格式，未定写"ch9999"）
    status:          当前状态（active/retired/dead/unknown）
    killable:        能不能写死（true/false）
    exit_chapter:    下线章节（退场/离开/死亡的章节）
    exit_type:       退场类型（见取值表）
    return_chapter:  回归章节（临时下线后回来的章节，可选）

## exit_type 取值表

| 值          | 说明             | 示例                    |
|-------------|------------------|-------------------------|
| dead        | 死亡             | 水老大ch095             |
| retired     | 退场（不死）     | 敖衍退位                |
| captured    | 被抓/被困        | 敖沉囚居                |
| banished    | 放逐/叛逃        | 白湮叛逃                |
| disappeared | 失踪             | 沧溟沉海                |
| temp_exit   | 临时下线（会回） | 某角色暂时离开          |
| ongoing     | 未下线（活跃）   | 主角、核心配角          |

## 成长弧线
- growth_arc:      分阶段状态变化（数组，每项包含）
    - stage:         阶段名称（如"卷一-卷三"）
      state:         该阶段的状态
      emotion:       该阶段的情绪基调

## 关系
- key_relationships:   核心关系（数组，每项包含）
    - target:          对象名字
      type:            关系类型（见取值表）
      note:            一句话描述

## 秘密
- secrets:         角色知道但读者暂时不知道的信息（数组格式）

## 约束
- constraints:     绝对不可违反的硬规则（数组格式）
                    写入 Tier1 基础约束

## 标志性物件
- signature_items: 反复出场的个人物品（数组格式）

#  三、取值表
# ════════════════════════════════════════════════════════════

## role_type（角色类型）

| 值             | 中文     | 说明                                   |
|----------------|----------|----------------------------------------|
| protagonist    | 主角     | 全书视角核心，每章出场                  |
| heroine        | 女主     | 该卷感情线核心，和主角有暧昧            |
| antagonist     | 反派     | 主要对手，和主角立场对立                |
| supporting     | 重要配角 | 多卷出场，对剧情有实质影响              |
| guest          | 客串     | 单卷或单章出场，用完就走                |
| system         | 系统/金手指 | 非人类，提供能力支持                |
| companion      | 伙伴/坐骑 | 长期跟随主角                          |
| background     | 背景人物 | 极少出场，世界背景的一部分              |

## 关系类型

| 值     | 说明                     |
|--------|--------------------------|
| 亲属   | 血缘关系                 |
| 师徒   | 师父/弟子                |
| 敌对   | 立场对立                 |
| 合作   | 共同目标                 |
| 暧昧   | 有好感但未明确           |
| 上下级 | 从属关系                 |
| 守护   | 保护与被保护             |
| 对立   | 有矛盾但不是死敌         |
| 中立   | 没有明显倾向             |

#  四、必填 vs 选填
# ════════════════════════════════════════════════════════════

## 必填字段（所有角色必须有）
  name, role_type, role_function, identity, personality,
  speaking_style, catchphrases, abilities, appearances, constraints

## 选填字段（有则填，没有写"无"）
  origin, appearance, emotional_baseline, personality_arc,
  growth_arc, key_relationships, secrets, signature_items


# ════════════════════════════════════════════════════════════
#  五、角色分层档案（按出场频率决定详细度）
# ════════════════════════════════════════════════════════════

角色档案不是所有人都写一样多。按出场频率分四档：

## Tier1 完整档案（主角+核心配角）
  - 适用：主角、女主、核心反派、系统/金手指
  - 要求：全部字段都要填
  - 示例：沈浮、乐园中枢、大嘴三姆

## Tier2 标准档案（多卷出场的重要角色）
  - 适用：多卷出场的配角、重要反派
  - 要求：必填字段 + 关键选填（key_relationships、constraints）
  - 示例：小丑贾克、蓝博、姜横

## Tier3 简略档案（单卷/单章出场）
  - 适用：单卷客串、一次性反派、工具人
  - 要求：只写必填字段（name、role_type、role_function、identity、constraints）
  - 示例：水老大、卫崇仓、厉戈

## Tier4 一行档案（背景人物）
  - 适用：极少出场、世界背景的一部分
  - 要求：name + role_type + role_function 一行搞定
  - 示例：韩嫂、白经理、柳半仙

# ── 分层速查表 ──

| 档  | 角色类型           | 字段数 | Token占用 | 示例           |
|-----|-------------------|--------|-----------|----------------|
| T1  | 主角/女主/核心反派 | 全部   | ~800-1200 | 沈浮、中枢     |
| T2  | 多卷配角          | 8-10个 | ~400-600  | 贾克、蓝博     |
| T3  | 单卷/单章客串     | 5-6个  | ~150-250  | 水老大、厉戈   |
| T4  | 背景人物          | 3个    | ~30-50    | 韩嫂、白经理   |

# ── 判断角色该归哪档 ──

1. 这个角色出场超过3卷？→ T1或T2
2. 这个角色有独立的growth_arc？→ T1或T2
3. 这个角色有key_relationships需要追踪？→ T1或T2
4. 这个角色只在某一卷出现？→ T3
5. 这个角色只在某一章出现？→ T3或T4
6. 这个角色是背景板（如"食堂主厨"）？→ T4

# ════════════════════════════════════════════════════════════
#  十四、与其他系统的关联
# ════════════════════════════════════════════════════════════

1. 别名系统
   - 角色档案.name → 别名系统.name（唯一标识）
   - 角色档案.role_type → 别名系统.time_layers（称呼随时间变化）

2. 说话风格格式规范
   - 角色档案.name → 说话风格.name（唯一标识）
   - 角色档案.speaking_style → 说话风格.signature_style

3. 角色关系图
   - 角色档案.key_relationships → 关系图的关系类型

4. 能力体系格式规范
   - 角色档案.abilities → 能力体系.天赋/境界
   - 角色档案.growth_arc → 能力体系.成长曲线

5. 角色能力状态系统
   - 角色档案.abilities → abilities.json（静态能力）
   - 角色档案.growth_arc → abilities.json（动态变化）

6. 物品格式规范
   - 角色档案.signature_items → 物品.name（标志性物品）
   - 角色档案.equipment → 物品（装备绑定）
   - 角色档案.inventory → 物品（背包绑定）

7. 场景切片格式规范
   - 角色档案.name → 场景切片.characters
   - 角色档案.appearances → 场景切片的出场记录

8. 伏笔系统
   - 角色档案.secrets → 伏笔的引入/推进
   - 角色档案.growth_arc → 伏笔的回收

9. 时间线格式规范
   - 角色档案.appearances → 时间线的出场记录
   - 角色档案.growth_arc → 时间线的事件节点

10. 势力组织格式规范
    - 角色档案.key_relationships → 势力组织.key_members
    - 角色档案.status → 势力组织.status

11. 爽点审查格式规范
    - 角色档案.growth_arc → 爽点的 executor/target
    - 角色档案.constraints → 爽点的约束

12. 细纲格式规范
    - 细纲.characters → 角色档案.name
    - 细纲.character_changes → 角色档案.growth_arc

13. 大纲格式规范
    - 大纲.protagonist → 角色档案.name
    - 大纲.new_characters → 角色档案.first_appearance

14. 上下文引擎
    - 角色档案 → 注入prompt（角色基本信息）
    - 角色档案.speaking_style → 注入prompt（对话风格）
    - 角色档案.constraints → 注入prompt（写作约束）
