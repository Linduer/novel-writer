# ============================================================
# 角色档案格式规范 v2.0
# 所有角色必须按此格式填写，字段不可省略
# ============================================================

# ════════════════════════════════════════════════════════════
#  一、字段分级（对应三级约束体系）
# ════════════════════════════════════════════════════════════

所有字段按"可变性"分为三档，冲突时高档优先。

## 第一档：基础性（绝对不可偏离）— Tier1

一旦写定永远不改，写入 Tier1 基础约束。

  name                    角色名
  role_type               角色类型
  identity                核心身份
  origin                  出身来历
  personality             性格底色（底层人格，不是情绪状态）
  abilities.天赋          天赋类型（innate，不可后天获得）
  abilities.境界突破节点  已写定的突破章节（如：江河402）
  constraints             硬规则
  signature_items         标志性物件（反复出场）
  appearance.memorable_detail  独特外貌细节（标志性特征）

## 第二档：可演变（随行文自然变化）— Tier2

会随剧情发展而变化，在 growth_arc 中分阶段记录。

  appearance.age          年龄（写范围，不写死数字）
  appearance.build        体型（受伤/锻炼后变化）
  appearance.signature    外观变化（换装备/留疤）
  emotional_baseline      情绪基线随经历改变
  catchphrases            口头禅会演变
  abilities.境界          实际境界提升
  abilities.战斗方式      战斗方式随能力变化
  abilities.特殊          特殊能力（后天获得的）
  key_relationships       关系类型变化
  secrets                 秘密可能被揭晓
  status                  在世状态（active→dead）
  growth_arc              成长弧线本身

## 第三档：可偏离（根据行文情况调整）— Tier3

每章可灵活调整，写完归档，下次覆盖。

  appearance.具体描写     同一个"偏瘦"，每章描述方式不同
  speaking_style.细节     同样报价式吐槽，具体台词每章不同
  role_function           核心功能不变，每章具体作用可微调
  personality_arc         总方向不变，措辞可调整


# ════════════════════════════════════════════════════════════
#  二、字段说明
# ════════════════════════════════════════════════════════════

## 基础信息
- name:             角色名（唯一标识，不可重复）
- role_type:        角色类型（见取值表）
- role_function:    角色功能（一句话说明这个角色在故事里干什么）

## 身份与背景
- identity:         一句话身份概括（50字以内）
- origin:           出身/来历（详细背景，100-200字）

## 外貌特征
- appearance:
    age:              年龄（写范围如"二十五六岁"，不写死数字）
    age_note:         年龄变化说明（可选，标注重大变化的章节节点）
    build:            体型
    signature:        标志性外观（一眼能认出的特征）
    memorable_detail: 独特细节（便于读者记忆的点）

## 性格
- personality:          核心性格（2-4个关键词+一句话描述）
- emotional_baseline:   默认情绪状态（不触发事件时是什么状态）
- personality_arc:      性格变化方向（从A到B的一句话描述）

## 说话风格
- speaking_style:   说话风格描述（一句话）
- catchphrases:     高频词/口头禅（3-5个，数组格式）

## 能力
- abilities:
    天赋:         天赋类型和效果（innate，Tier1不可变）
    境界:         当前境界（Tier2可演变，无修为写"无"）
    特殊:         特殊能力或限制（后天获得的放这里）
    战斗方式:     怎么打架（不写战斗的角色写"不参战"）

## 出场规划
- appearances:
    first_chapter: 首次出场章节（chNNNN格式）
    last_chapter:  最后出场章节（chNNNN格式，未定写"ch9999"）
    status:        当前状态（active/retired/dead/unknown）
    killable:      能不能写死（true/false）

## 成长弧线
- growth_arc:      分阶段状态变化（数组，每项包含）
    - stage:         阶段名称（如"卷一-卷三"）
      state:         该阶段的状态
      emotion:       该阶段的情绪基调

## 关系
- key_relationships:   核心关系（数组，每项包含）
    - target:          对象名字
      type:            关系类型（见取值表）
      note:            一句话描述

## 秘密
- secrets:         角色知道但读者暂时不知道的信息（数组格式）

## 约束
- constraints:     绝对不可违反的硬规则（数组格式）
                    写入 Tier1 基础约束

## 标志性物件
- signature_items: 反复出场的个人物品（数组格式）


# ════════════════════════════════════════════════════════════
#  三、取值表
# ════════════════════════════════════════════════════════════

## role_type（角色类型）

| 值             | 中文     | 说明                                   |
|----------------|----------|----------------------------------------|
| protagonist    | 主角     | 全书视角核心，每章出场                  |
| heroine        | 女主     | 该卷感情线核心，和主角有暧昧            |
| antagonist     | 反派     | 主要对手，和主角立场对立                |
| supporting     | 重要配角 | 多卷出场，对剧情有实质影响              |
| guest          | 客串     | 单卷或单章出场，用完就走                |
| system         | 系统/金手指 | 非人类，提供能力支持                |
| companion      | 伙伴/坐骑 | 长期跟随主角                          |
| background     | 背景人物 | 极少出场，世界背景的一部分              |

## 关系类型

| 值     | 说明                     |
|--------|--------------------------|
| 亲属   | 血缘关系                 |
| 师徒   | 师父/弟子                |
| 敌对   | 立场对立                 |
| 合作   | 共同目标                 |
| 暧昧   | 有好感但未明确           |
| 上下级 | 从属关系                 |
| 守护   | 保护与被保护             |
| 对立   | 有矛盾但不是死敌         |
| 中立   | 没有明显倾向             |


# ════════════════════════════════════════════════════════════
#  四、必填 vs 选填
# ════════════════════════════════════════════════════════════

## 必填字段（所有角色必须有）
  name, role_type, role_function, identity, personality,
  speaking_style, catchphrases, abilities, appearances, constraints

## 选填字段（有则填，没有写"无"）
  origin, appearance, emotional_baseline, personality_arc,
  growth_arc, key_relationships, secrets, signature_items
