# ============================================================
# 场景切片格式规范 v1.0
# 将章节拆分为场景，每个场景有明确的五要素
# ============================================================

# ════════════════════════════════════════════════════════════
#  一、为什么需要场景切片
# ════════════════════════════════════════════════════════════

一个章节可能有多个场景，不切片会导致：
  1. 不知道某个场景发生在哪
  2. 不知道某个场景有哪些人
  3. 不知道某个场景的情绪走向
  4. 不知道场景之间的转换是否流畅

场景切片的好处：
  1. 写作时知道每段该写什么
  2. 审查时知道场景转换是否流畅
  3. 检查时知道人物/地点是否一致

# ════════════════════════════════════════════════════════════
#  二、字段分级
# ════════════════════════════════════════════════════════════

## Tier1 基础性（绝对不可偏离）

  scene_id                场景ID（chNNNN_SNN格式）
  chapter                 所属章节
  order                   场景顺序（1,2,3...）
  location                场景地点（对应地点档案）
  characters              场景人物列表
  pov                     视角人物（谁的视角）
  time                    时间（白天/夜晚/具体时间）
  event                   核心事件（一句话）

## Tier2 可演变（随剧情自然变化）

  emotion_start           场景开始时的情绪
  emotion_end             场景结束时的情绪
  conflict                场景冲突/张力
  tension_level           紧张度（1-10）
  pacing                  节奏（快/中/慢）
  transition_in           进入方式（怎么进入这个场景）
  transition_out          退出方式（怎么离开这个场景）

## Tier3 可偏离（根据行文情况调整）

  atmosphere              氛围描写
  sensory_details         感官细节
  dialogue_style          对话风格


# ════════════════════════════════════════════════════════════
#  三、取值表
# ════════════════════════════════════════════════════════════

## emotion（情绪类型）

| 值        | 说明     | 适用场景            |
|-----------|----------|---------------------|
| 平静      | 日常     | 过渡、交代          |
| 轻松      | 搞笑     | 日常、吐槽          |
| 紧张      | 危机     | 战斗、逃亡          |
| 悲伤      | 离别     | 死亡、分手          |
| 愤怒      | 冲突     | 争吵、对峙          |
| 喜悦      | 胜利     | 突破、成功          |
| 恐惧      | 危险     | 面对强敌            |
| 震惊      | 反转     | 真相揭露            |
| 温暖      | 感动     | 守护、牺牲          |
| 绝望      | 低谷     | 真败、至暗时刻      |
| 释然      | 放下     | 和解、告别          |
| 决心      | 抉择     | 重大决定            |

## tension_level（紧张度）

| 等级 | 说明 | 对应场景 |
|------|------|----------|
| 1-2  | 日常 | 聊天、交代 |
| 3-4  | 轻微冲突 | 争吵、质疑 |
| 5-6  | 中等紧张 | 对峙、谈判 |
| 7-8  | 高度紧张 | 战斗、逃亡 |
| 9-10 | 极度紧张 | 生死、终战 |

## pacing（节奏）

| 值    | 说明           | 句式特点          |
|-------|----------------|-------------------|
| 快    | 紧迫、动作     | 短句、动词多      |
| 中    | 正常叙事       | 长短句交替        |
| 慢    | 抒情、回忆     | 长句、描写多      |

## transition（场景转换方式）

| 值        | 说明           | 示例                |
|-----------|----------------|---------------------|
| cut       | 硬切           | 直接跳转            |
| fade      | 淡入淡出       | 时间流逝            |
| action    | 动作转场       | 角色走动            |
| dialogue  | 对话转场       | "走吧"→下一个场景  |
| object    | 物件转场       | 看向某个物件→回忆  |
| sound     | 声音转场       | 广播声→下一个场景  |
| time      | 时间跳跃       | "三天后"            |


# ════════════════════════════════════════════════════════════
#  四、字段说明
# ════════════════════════════════════════════════════════════

## 基础信息
- scene_id:          场景ID（chNNNN_SNN格式，如ch0001_S01）
- chapter:           所属章节（chNNNN格式）
- order:             场景顺序（1,2,3...）
- location:          场景地点（对应地点档案的name）
- characters:        场景人物列表（数组）
- pov:               视角人物（谁的视角）
- time:              时间（白天/夜晚/具体时间）
- event:             核心事件（一句话）

## 情绪与节奏
- emotion_start:     场景开始时的情绪
- emotion_end:       场景结束时的情绪
- conflict:          场景冲突/张力
- tension_level:     紧张度（1-10）
- pacing:            节奏（快/中/慢）

## 场景转换
- transition_in:     进入方式（怎么进入这个场景）
- transition_out:    退出方式（怎么离开这个场景）

## 氛围描写
- atmosphere:        氛围描写（一句话）
- sensory_details:   感官细节（声音/气味/温度）
- dialogue_style:    对话风格

# ════════════════════════════════════════════════════════════
#  六、场景切片文件结构
# ════════════════════════════════════════════════════════════

每个章节可以有一个场景切片文件：

data/{项目名}/chapters/ch{NNNN}/
├── draft.txt           # 正文草稿
├── final.txt           # 最终版
├── metadata.json       # 章节元数据
├── memory.json         # 章节记忆
├── scenes.json         # 场景切片（新增）
└── backups/            # 备份

# ════════════════════════════════════════════════════════════
#  七、与其他系统的关联
# ════════════════════════════════════════════════════════════

1. 地点档案
   - 场景的 location → 地点的 name
   - 场景的 atmosphere → 地点的 atmosphere

2. 角色档案
   - 场景的 characters → 角色的 name
   - 场景的 pov → 角色的 speaking_style

3. 说话风格
   - 场景的 dialogue_style → 角色的 signature_style

4. 伏笔系统
   - 场景的 event → 伏笔的引入/推进/回收章节

5. 上下文引擎
   - 当前章节的场景切片 → 注入prompt
   - 帮助LLM理解场景结构
