# ════════════════════════════════════════════════════════════
#  一、为什么需要势力系统
# ════════════════════════════════════════════════════════════

长篇小说中势力众多，不管理会出问题：
  1. 不知道某个势力的立场是什么
  2. 不知道势力之间的关系
  3. 角色所属势力变化时没有追踪
  4. 势力的消亡/崛起没有记录

# ════════════════════════════════════════════════════════════
#  二、字段分级
# ════════════════════════════════════════════════════════════

## Tier1 基础性（绝对不可偏离）

  name                    势力名称（唯一标识）
  type                    势力类型（见取值表）
  leader                  首领/掌门
  ideology                核心理念/宗旨
  territory               势力范围/地盘
  first_appearance        首次出场章节
  constraints             势力的硬规则/禁忌

## Tier2 可演变（随剧情自然变化）

  status                  势力状态（active/destroyed/merged/expanded）
  member_count            成员数量
  allies                  盟友势力列表
  enemies                 敌对势力列表
  key_members             核心成员列表
  power_level             势力强度（弱/中/强/极强）
  key_events              势力关键事件
  dissolution_chapter     势力消亡章节

## Tier3 可偏离（根据行文情况调整）

  description             势力描述（每章可微调）
  reputation              外界对势力的评价


# ════════════════════════════════════════════════════════════
#  三、取值表
# ════════════════════════════════════════════════════════════

## type（势力类型）

| 值         | 说明       | 示例                    |
|------------|------------|-------------------------|
| faction    | 阵营/门派  | 归墟教、沧澜遗族        |
| guild      | 公会/组织  | 义盟、天工阁            |
| military   | 军事组织   | 掠夺王庭、仙城守军      |
| merchant   | 商业组织   | 商路网                  |
| family     | 家族/血脉  | 沈家、黑鲨王族          |
| school     | 学院/门派  | 乐园学校                |
| religion   | 宗教/信仰  | 归墟教                  |
| government | 政府/政权  | 四海会盟                |
| criminal   | 犯罪组织   | 黑帮                    |
| alliance   | 联盟       | 四海会盟                |

## status（势力状态）

| 值          | 说明           |
|-------------|----------------|
| active      | 活跃           |
| destroyed   | 已毁灭         |
| merged      | 已合并         |
| expanded    | 已扩张         |
| declining   | 衰落中         |
| rising      | 崛起中         |
| hidden      | 隐藏/潜伏     |
| dissolved   | 已解散         |

## power_level（势力强度）

| 值    | 说明   | 示例            |
|-------|--------|-----------------|
| weak  | 弱小   | 小型海盗团      |
| mid   | 中等   | 一般门派        |
| strong| 强大   | 义盟、天工阁    |
| super | 极强   | 归墟教、沧溟    |


# ════════════════════════════════════════════════════════════
#  四、字段说明
# ════════════════════════════════════════════════════════════

## 基础信息
- name:               势力名称（唯一标识）
- type:               势力类型（见取值表）
- leader:             首领/掌门
- ideology:           核心理念/宗旨
- territory:          势力范围/地盘
- first_appearance:   首次出场章节
- constraints:        势力的硬规则/禁忌

## 状态追踪
- status:             当前状态（见取值表）
- member_count:       成员数量
- power_level:        势力强度
- key_events:         势力关键事件（数组）
- dissolution_chapter: 势力消亡章节

## 关系网络
- allies:             盟友势力列表
- enemies:            敌对势力列表
- key_members:        核心成员列表

## 氛围描述
- description:        势力描述（一句话）
- reputation:         外界对势力的评价

# ════════════════════════════════════════════════════════════
#  六、与其他系统的关联
# ════════════════════════════════════════════════════════════

1. 角色档案
   - 角色的 key_relationships → 势力的 key_members
   - 角色的 status → 势力的 status

2. 角色关系图
   - 势力之间的 allies/enemies → 关系图中的关系类型

3. 地点档案
   - 势力的 territory → 地点的 owner

4. 时间线
   - 势力的 key_events → 时间线的事件节点
   - 势力的 dissolution_chapter → 时间线的势力消亡

5. 伏笔系统
   - 势力的关键事件 → 伏笔的引入/推进/回收

6. 别名系统
   - 势力的别名 → 别名系统（势力也有别名，如"义盟"也叫"开源派"）
   - 势力名称的变化 → 别名系统的时间维度记录

7. 细纲
   - 势力的关键事件 → 细纲的剧情规划
   - 细纲.character_changes.type=faction → 势力的状态更新

8. 场景切片
   - 势力的 territory → 场景切片的 location
   - 势力的 key_members → 场景切片的 characters

9. 爽点审查
   - 势力的关键事件 → 爽点审查的记录
   - 势力的兴衰 → 爽点审查的节奏分布
