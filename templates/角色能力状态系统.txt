# ════════════════════════════════════════════════════════════
#  三、字段说明
# ════════════════════════════════════════════════════════════

## 全局字段
- last_update_chapter:    最后更新的章节（chNNNN格式）
- characters:             所有角色的能力状态

## 角色字段（每个角色）
- current_realm:          当前境界（对应能力体系的境界等级）
- realm_progress:         境界进度（0-100，突破时到100）
- talents:                当前拥有的天赋列表
- unlocked_facilities:    已解锁的设施列表
- keys_collected:         已收集的五钥列表
- belongings:             当前持有的物品
- status:                 当前状态（active/dead/retired/unknown）
- last_ability_change:    最后一次能力变化的章节
- notes:                  备注（特殊情况说明）

## 角色特定字段（根据角色类型可选）
- star_level:             英灵星级（1-3）
- awakened:               是否三星觉醒（true/false）
- silence_count:          中枢静默次数
- confession_done:        中枢是否坦白
- (其他根据需要添加)

# ════════════════════════════════════════════════════════════
#  五、更新流程
# ════════════════════════════════════════════════════════════

写完每章后自动更新流程：

1. LLM提取章节记忆时，同时提取能力变化
2. 将能力变化写入 ability_log.jsonl
3. 更新 abilities.json 中对应角色的状态
4. 更新 last_update_chapter

## 触发更新的事件

| 事件 | 更新内容 |
|------|----------|
| 角色突破境界 | current_realm, realm_progress |
| 角色三星觉醒 | star_level, awakened |
| 解锁新设施 | unlocked_facilities |
| 获取新物品 | belongings |
| 角色死亡/退场 | status |
| 角色首次出场 | 添加新角色条目 |
| 中枢静默 | silence_count |
| 中枢坦白 | confession_done |
| 获取新钥匙 | keys_collected |

# ════════════════════════════════════════════════════════════
#  六、上下文引擎集成
# ════════════════════════════════════════════════════════════

上下文引擎在组装prompt时会读取abilities.json：

1. 读取当前章节之前的所有角色状态
2. 只加载当前章节出场角色的能力状态
3. 注入到prompt中，让LLM知道角色当前能力

## Token预算分配

能力状态占Token预算的2%（约256 tokens for 128K context）：

  当前章节出场角色的能力状态：~200 tokens
  最近一次能力变化日志：~56 tokens

# ════════════════════════════════════════════════════════════
#  七、查询命令
# ════════════════════════════════════════════════════════════

python main.py abilities                    # 查看所有角色当前能力状态
python main.py abilities --character 沈浮   # 查看特定角色能力状态
python main.py abilities --log             # 查看能力变化日志
python main.py abilities --log --chapter ch0402  # 查看特定章节的能力变化
python main.py abilities --diff ch001 ch402 # 对比两个章节的能力差异


# ════════════════════════════════════════════════════════════
#  八、与其他系统的关联
# ════════════════════════════════════════════════════════════

1. 能力体系格式规范
   - abilities.json.current_realm → 能力体系.境界等级
   - abilities.json.talents → 能力体系.天赋类型
   - abilities.json.unlocked_facilities → 能力体系.设施解锁

2. 角色档案
   - abilities.json → 角色档案.abilities（静态能力）
   - abilities.json → 角色档案.growth_arc（动态变化）

3. 物品格式规范
   - abilities.json.equipped_items → 物品格式规范（装备绑定）
   - 物品获取/丢失 → 必须更新 abilities.json

4. 说话风格
   - abilities.json.current_realm → 可能影响说话风格（如三姆觉醒后）
   - 说话风格.growth_notes → 可能引用能力变化

5. 别名系统
   - abilities.json.current_realm → 可能影响别名（如觉醒后称号变化）
   - 别名系统的时间维度记录 → 可能引用能力变化

6. 场景切片
   - abilities.json → 场景切片的战斗场景（角色当前能力）
   - 场景切片的事件 → 可能触发 abilities.json 的更新

7. 细纲
   - 细纲.character_changes.type=realm → 更新 abilities.json.current_realm
   - 细纲.character_changes.type=ability → 更新 abilities.json.talents

8. 上下文引擎
   - abilities.json → 注入prompt（当前角色能力状态）
   - 帮助LLM理解角色当前实力
