# ── 关系类型取值表 ──

## 基础关系（静态）
| 值     | 说明           | 示例                      |
|--------|----------------|---------------------------|
| 亲属   | 血缘关系       | 父女/兄弟/姐妹            |
| 师徒   | 师父/弟子      | 贾克→季小满               |
| 上下级 | 从属关系       | 沧溟→三姆                 |
| 契约   | 非血缘绑定     | 铁鳌蟹将→乐园             |

## 情感关系（可变）
| 值     | 说明           | 示例                      |
|--------|----------------|---------------------------|
| 暧昧   | 有好感未明确   | 沈浮←→程霜               |
| 暗恋   | 单方面好感     | A暗恋B，B不知道           |
| 明恋   | 公开追求       | A公开追B                  |
| 情敌   | 竞争同一对象   | A和B都追C                 |
| 分手   | 曾经在一起     | 前任关系                  |
| 复合   | 分手后重来     | 破镜重圆                  |

## 利益关系（动态）
| 值     | 说明           | 示例                      |
|--------|----------------|---------------------------|
| 合作   | 共同目标       | 沈浮←→中枢               |
| 盟友   | 利益绑定       | 四海会盟                  |
| 利用   | 单方面利用     | A利用B达成目的            |
| 互相利用 | 双方各取所需 | 教主←→渊                 |
| 利益共同体 | 一荣俱荣   | 乐园全员                  |

## 对立关系（可转化）
| 值     | 说明           | 示例                      |
|--------|----------------|---------------------------|
| 敌对   | 立场对立       | 沈浮←→渊                 |
| 对立   | 有矛盾不死敌   | 沈浮←→敖涸（前期）       |
| 情敌   | 竞争同一对象   | A和B都追C                 |
| 背叛   | 曾经信任→反目  | 敖泓背叛沧澜              |
| 复仇   | 有血仇要报     | A杀B家人，B要报仇         |

## 保护关系（可变）
| 值     | 说明           | 示例                      |
|--------|----------------|---------------------------|
| 守护   | 保护与被保护   | 三姆→沈浮                 |
| 跟班   | 追随某人       | 小弟→老大                 |
| 救命   | A救过B的命     | 某人被主角救过             |
| 被救   | 被某人救过     | 被主角救过                 |

## 转化关系（剧情推进）
| 值     | 说明           | 示例                      |
|--------|----------------|---------------------------|
| 友转敌 | 朋友变敌人     | 背叛剧情                  |
| 敌转友 | 敌人变朋友     | 敖涸归队                  |
| 师转敌 | 师父变敌人     | 反转剧情                  |
| 恋转敌 | 恋人变敌人     | 爱情悲剧                  |
| 敌转恋 | 敌人变恋人     | 爱情喜剧/虐恋             |
| 陌生人→恋人 | 从不认识到相爱 | 日久生情              |

# ── 格式说明 ──

每条关系格式：
  来源 → 目标: 关系类型（描述）

关系可以双向标注：
  A → B: 暧昧（A对B有好感）
  B → A: 守护（B保护A）

转化关系用箭头标注变化：
  A → B: 敌对→合作（卷三归队）
