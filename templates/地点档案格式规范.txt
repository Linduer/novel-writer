#  一、字段分级（对应三级约束体系）
# ════════════════════════════════════════════════════════════

## 第一档：基础性（绝对不可偏离）— Tier1

一旦写定永远不改。

  name                    地点名称（唯一标识）
  type                    地点类型（见取值表）
  region                  所属区域（在哪个大区域里）
  first_appearance        首次出场章节
  description             地点描述（一句话定性）
  function                地点功能（在故事里干什么）
  constraints             地点的硬规则/禁忌
  key_events              在此发生的关键事件（标注章节）

## 第二档：可演变（随剧情自然变化）— Tier2

  owner                   地点归属（谁控制/管理）
  status                  地点状态（active/destroyed/abandoned/captured）
  control_changes         控制权变化（谁→谁，哪章）
  damage_level            损坏程度（完好/轻损/重损/废墟）
  unlock_chapter          解锁/发现章节
  destroy_chapter         毁灭/废弃章节
  linked_facility         关联设施（乐园设施对应）

## 第三档：可偏离（根据行文情况调整）— Tier3

  atmosphere              氛围描写（每章可不同）
  appearance_description  具体外观（每章可不同）
  sensory_details         感官细节（声音/气味/温度）

## status（地点状态）

| 值          | 说明           |
|-------------|----------------|
| active      | 正常使用中     |

## 关键事件类型

| 类型     | 说明           | 示例                    |
|----------|----------------|-------------------------|
| battle   | 战斗/战争      | 满潮夜、终战            |

| death    | 角色死亡       | 殉园、坐化              |
| unlock   | 能力解锁       | 设施首秀、境界突破      |
| romance  | 感情线         | 倒戈、告白              |
| ritual   | 仪式/庆典       | 开业、免票              |
| mystery  | 谜团揭晓       | 真相、秘密              |


# ════════════════════════════════════════════════════════════
#  三、字段说明
# ════════════════════════════════════════════════════════════

## 基础信息
- name:               地点名称（唯一标识）
- type:               地点类型（见取值表）
- region:             所属区域（在哪个大区域里）
- first_appearance:   首次出场章节（chNNNN格式）
- description:        地点描述（一句话定性）
- function:           地点功能（在故事里干什么）

## 规则与事件
- constraints:        地点的硬规则/禁忌
- key_events:         在此发生的关键事件（数组，每项标注章节）

## 状态追踪
- owner:              地点归属（谁控制/管理）
- status:             当前状态（见取值表）
- control_changes:    控制权变化历史（数组）
- damage_level:       损坏程度（完好/轻损/重损/废墟）
- unlock_chapter:     解锁/发现章节
- destroy_chapter:    毁灭/废弃章节
- linked_facility:    关联设施（乐园设施对应）

## 氛围描写
- atmosphere:         氛围描写（一句话）
- appearance_description: 具体外观（每章可不同）
- sensory_details:    感官细节（声音/气味/温度）

室内恒温   → 设施.室内恒温水世界（神通：领域雏形）
海啸池     → 设施.海啸池（神通：压卷杀招）
儿童戏水池 → 设施.儿童戏水池（神通：起手水术）

地点的 key_events 与伏笔系统关联：
  key_events 中的章节 → 伏笔的引入/推进/回收章节

#  六、与其他系统的关联
# ════════════════════════════════════════════════════════════

地点档案与其他系统的关联：

1. 能力体系
   - 乐园设施 → 设施即神通
   - 地点的 linked_facility 字段绑定

2. 伏笔系统
   - key_events 中的章节 → 伏笔的引入/推进/回收

3. 角色档案
   - 地点的 owner 字段 → 角色的 key_relationships
   - 地点的 key_events → 角色的 growth_arc

4. 时间线
   - 地点的 key_events → 时间线的事件节点
   - 地点的 first_appearance → 时间线的地点引入

5. 场景切片
   - 地点的 name → 场景切片的 location
   - 地点的 atmosphere → 场景切片的 atmosphere

6. 别名系统
   - 地点的别名 → 别名系统（地点也有别名，如"沧浪池"也叫"泳池"）
   - 地点名称的变化 → 别名系统的时间维度记录

7. 势力组织
   - 地点的 owner → 势力组织的 territory
   - 地点的 key_events → 势力组织的关键事件

8. 爽点审查
   - 地点的 key_events → 爽点审查的记录
   - 地点的 atmosphere → 爽点审查的节奏分布

9. 大纲
   - 地点的 first_appearance → 大纲的 new_locations
   - 地点的 key_events → 大纲的 key_events

10. 上下文引擎
    - 当前章节出场地点 → 注入prompt
    - 地点的 atmosphere → 帮助LLM营造氛围
