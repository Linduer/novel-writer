#  一、字段分级（对应三级约束体系）
# ════════════════════════════════════════════════════════════

## 第一档：基础性（绝对不可偏离）— Tier1

一旦写定永远不改。

  name                    物品名称（唯一标识）
  type                    物品类型（见取值表）
  rarity                  稀有度（见取值表）
  description             物品描述（一句话）
  origin                  物品来历（从哪来的）
  owner                   物品归属（属于谁）
  constraints             使用限制/禁忌

## 第二档：可演变（随剧情自然变化）— Tier2

  durability              耐久度（使用次数/损坏进度）
  enhancement             强化等级（+1到+15）
  current_holder          当前持有者（可能转移）
  is_destroyed            是否已损坏/销毁
  acquisition_chapter     获取章节
  destruction_chapter     失去/销毁章节

## 第三档：可偏离（根据行文情况调整）— Tier3

  appearance_description  具体外观描写（每章可不同）
  usage_description       具体使用方式（每章可不同）

#  二、取值表
# ════════════════════════════════════════════════════════════

## type（物品类型）

| 值         | 说明       | 示例                    |
|------------|------------|-------------------------|
| weapon     | 武器       | 剑、枪、钩子            |
| armor      | 防具       | 盔甲、盾牌              |
| accessory  | 饰品       | 项链、戒指              |
| consumable | 消耗品     | 药水、弹药              |
| key_item   | 关键物品   | 钥匙、地图、信物        |
| tool       | 工具       | 检票钳、笔记本          |
| pet        | 契约生物   | 海兽、坐骑              |
| facility   | 设施权限   | 乐园设施                |
| currency   | 货币       | 信仰值、金币            |
| material   | 材料       | 矿石、布料              |
| scroll     | 卷轴/技能书 | 技能书、配方           |

## rarity（稀有度）

| 值      | 说明     | 概率   |
|---------|----------|--------|
| common  | 普通     | 70%    |
| uncommon| 优秀     | 20%    |
| rare    | 稀有     | 8%     |
| epic    | 史诗     | 1.5%   |
| legend  | 传说     | 0.4%   |
| mythic  | 神话     | 0.1%   |

## rarity 对应光色（打捞系统）

| 稀有度 | 光色 | 说明 |
|--------|------|------|
| common | 白光 | "垃圾"（后文必须翻案） |
| uncommon | 白光 | 稍好的"垃圾" |
| rare | 紫光 | 出图纸或英灵 |
| epic | 紫光 | 高级图纸或英灵 |
| legend | 金光 | 出神器 |
| mythic | 金光 | 终极神器 |

## 状态标记

| 值        | 说明       |
|-----------|------------|
| intact    | 完好       |
| damaged   | 损坏       |
| broken    | 毁坏       |
| lost      | 丢失       |
| consumed  | 已消耗     |
| transferred | 已转移  |


# ════════════════════════════════════════════════════════════
#  三、字段说明
# ════════════════════════════════════════════════════════════

## 基础信息
- name:               物品名称（唯一标识）
- type:               物品类型（见取值表）
- rarity:             稀有度（见取值表）
- description:        物品描述（一句话）

## 来源与归属
- origin:             物品来历（打捞/购买/赠予/制作）
- owner:              物品归属（属于谁）
- current_holder:     当前持有者（可能与owner不同）

## 使用规则
- constraints:        使用限制/禁忌
- durability:         耐久度（可选，需要追踪耐久的物品填）
- enhancement:        强化等级（可选，有强化系统的物品填）

## 状态追踪
- is_destroyed:       是否已损坏/销毁
- acquisition_chapter: 获取章节
- destruction_chapter: 失去/销毁章节
- status:             当前状态（intact/damaged/broken/lost/consumed/transferred）

## 外观描述
- appearance_description: 具体外观描写（每章可不同）

# ════════════════════════════════════════════════════════════
#  五、与角色档案的绑定
# ════════════════════════════════════════════════════════════

角色档案中的物品字段与物品格式规范的对应关系：

角色档案字段              物品格式规范
─────────────────────────────────────
signature_items     →    name + type + rarity
equipment.*         →    name + type + constraints
inventory.fixed     →    name + type + constraints
inventory.consumable →   name + type + durability
inventory.key_items →    name + type + acquisition_chapter

## 绑定示例

# 角色档案
- name: 沈浮
  signature_items: ["招牌", "检票钳", "爷爷的照片"]
  equipment:
    主手: 无（不参与战斗）
    副手: 检票钳
    防具: 无
    饰品: 无
    特殊: 乐园设施权限
  inventory:
    固定物品: ["招牌", "检票钳", "爷爷的照片"]
    消耗品: 无
    关键物品: ["甘霖瓶", "潮汐之心"]

# 对应的物品档案
- name: 招牌
  type: key_item
  rarity: legend
  ...

- name: 检票钳
  type: tool
  rarity: uncommon
  ...

- name: 甘霖瓶
  type: key_item
  rarity: mythic
  ...


# ════════════════════════════════════════════════════════════
#  六、与能力体系的绑定
# ════════════════════════════════════════════════════════════

物品与能力体系的对应关系：

物品格式规范                能力体系格式规范
─────────────────────────────────────
key_item (五钥类)      →    五钥收集进度
key_item (设施权限类)  →    设施解锁进度
consumable (甘霖类)    →    信仰值消耗
weapon (武器类)        →    abilities.战斗方式
tool (工具类)          →    abilities.特殊能力

## 五钥绑定

五钥类物品必须与能力体系的"五钥收集进度"绑定：

物品名称          能力体系字段           获取章节
─────────────────────────────────────────────
甘霖瓶          → 五钥.第一钥_甘霖瓶    ch0001
潮汐之心        → 五钥.第二钥_潮汐之心  ch241
玉玺            → 五钥.第三钥_玉玺      ch469
灯塔火种        → 五钥.第四钥_灯塔火种  ch592
沧溟本体        → 五钥.第五钥_沧溟本体  ch621

## 绑定规则

1. 五钥类物品获取时，必须同时更新能力体系的五钥收集进度
2. 五钥类物品丢失/损坏时，必须同时更新能力体系
3. 设施权限类物品解锁时，必须同时更新能力体系的设施解锁进度
4. 消耗品使用时，必须同时更新能力体系的信仰值存量


# ════════════════════════════════════════════════════════════
#  七、与其他系统的关联
# ════════════════════════════════════════════════════════════

1. 角色档案
   - 物品的 owner → 角色的 signature_items/equipment/inventory
   - 物品的 acquisition_chapter → 角色的 first_appearance

2. 能力体系格式规范
   - 物品的五钥类 → 能力体系.五钥收集进度
   - 物品的设施权限类 → 能力体系.设施解锁进度
   - 物品的消耗品 → 能力体系.信仰值

3. 角色能力状态系统
   - 物品的装备绑定 → abilities.json.equipped_items
   - 物品获取/丢失 → 必须更新 abilities.json

4. 场景切片
   - 物品的使用 → 场景切片的 event
   - 物品的状态变化 → 场景切片的 tension_level

5. 细纲
   - 细纲.character_changes.type=item → 物品的状态更新
   - 细纲生成时涉及物品 → 必须参考物品格式规范

6. 时间线
   - 物品的 acquisition_chapter → 时间线的时间点
   - 物品的 destruction_chapter → 时间线的时间点

7. 伏笔系统
   - 物品的隐藏效果 → 伏笔的引入/推进
   - 物品的真相 → 伏笔的回收

8. 爽点审查
   - 物品的获取 → 爽点的收获类型
   - 物品的隐藏效果揭晓 → 爽点的揭秘类型

9. 上下文引擎
   - 当前章节出场角色的物品 → 注入prompt
   - 帮助LLM理解角色拥有的物品
