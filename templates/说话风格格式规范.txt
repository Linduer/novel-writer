# 说话风格格式规范 v1.0
# 所有角色必须按此格式填写说话风格
# ============================================================

# ════════════════════════════════════════════════════════════
#  一、字段分级（对应三级约束体系）
# ════════════════════════════════════════════════════════════

所有字段按"可变性"分为三档，冲突时高档优先。

## 第一档：基础性（绝对不可偏离）— Tier1

一旦写定永远不改，写入 Tier1 基础约束。

  name                    角色名
  signature_style         核心说话方式（一句话定性，不可变）
  catchphrases            标志性口头禅（3-5个，不可替换）
  forbidden_patterns      绝对不能出现的说话方式
  constraints             硬规则（如"关键场合收短句"）

## 第二档：可演变（随行文自然变化）— Tier2

会随剧情发展而变化，在 growth_arc 中分阶段记录。

  catchphrases            口头禅会演变（如"本中枢"→"俺"）
  vocabulary_level        用词层次（随角色成长变化）
  emotional_range         情绪表达范围（随经历变化）
  growth_notes            风格变化说明（哪个阶段怎么变）

## 第三档：可偏离（根据行文情况调整）— Tier3

每章可灵活调整，写完归档，下次覆盖。

  example_lines           具体示例台词（每章可以不同）
  tempo                   节奏（快/慢/顿挫，随场景变）
  register                语域（正式/随意，随对象变）
  tone                    语气（愤怒/平静/调侃，随情节变）


# ════════════════════════════════════════════════════════════
#  二、字段说明
# ════════════════════════════════════════════════════════════

## 核心身份
- name:                 角色名（与角色档案一致）

## 基础说话方式（Tier1）
- signature_style:      一句话描述核心说话方式
                        例："报价式吐槽，万物可折成票价"
                        例："播报体，开头'叮！'，附注毒舌"
                        例："短句大嗓门，平时更憨，战时下令像换人"

- catchphrases:         标志性口头禅/高频词（3-5个）
                        这是角色的"声音指纹"，读者一看到就知道是谁在说话

- forbidden_patterns:   绝对不能出现的说话方式
                        例：沈浮"不许油滑"，霍青澜"不许文绉绉"
                        这是硬边界，写了就不动

- constraints:          其他硬规则
                        例："嘴贫不许油滑：贫是铠甲，关键场合收短句"
                        例："自称演变：本中枢→俺（839起）"

## 可演变字段（Tier2）
- vocabulary_level:     用词层次
                        例："报价式"（沈浮），"文士腔"（敖涸），"科学腔"（公输瑶）
                        随角色成长可以变化（如白湮从"空白页"到有温度的表达）

- emotional_range:      情绪表达范围
                        例："表面松弛底层焦虑"（沈浮），"冷面不许无情"（雾隐千黛）
                        随经历可以扩展或收缩

- growth_notes:         风格变化说明
                        例："中枢839起自称从'本中枢'变'俺'"
                        例："白湮从复读机到有温度的表达"
                        在 growth_arc 中记录

## 可偏离字段（Tier3）
- example_lines:        示例台词（3-5句）
                        这是"示范"，不是"台词库"
                        每章可以生成新的，不需要重复使用这些

- tempo:                节奏
                        例："快节奏短句"（三姆），"顿挫有致"（敖涸），"慢热"（白湮）

- register:             语域
                        例："公文腔"（程霜），"营业腔"（中枢），"海盗腔"（霍青澜）

- tone:                 语气
                        例："报价式调侃"（沈浮），"毒舌"（中枢），"较真"（姗姗）


# ════════════════════════════════════════════════════════════
#  三、取值表
# ════════════════════════════════════════════════════════════

## signature_style 常见模式

| 模式 | 说明 | 示例角色 |
|------|------|----------|
| 报价式吐槽 | 万物可折成票价/成本 | 沈浮 |
| 播报体 | 以"叮"开头，正式播报 | 乐园中枢 |
| 短句大嗓门 | 简短有力，不啰嗦 | 大嘴三姆 |
| 相声腔 | 金句制造机，有捧哏感 | 小丑贾克 |
| 公文腔 | 严谨、书面、偶尔露怯 | 程霜 |
| 海盗腔 | 豪爽直接，不绕弯 | 霍青澜 |
| 冷面精准 | 话少但每句到位 | 雾隐千黛 |
| 文士腔 | 古风、账房逻辑 | 敖涸 |
| 科学腔 | 数据、检测、专业术语 | 公输瑶 |
| 较真腔 | 认死理，一步不让 | 姗姗 |

## forbidden_patterns 常见类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 语气禁止 | 某种语气不能出现 | 沈浮：不许油滑 |
| 措辞禁止 | 某类词不能用 | 霍青澜：不许文绉绉 |
| 风格禁止 | 某种说话方式不能出现 | 沧溟：不许抢主角的戏 |
| 时机禁止 | 某些场合不能说 | 中枢：坦白前不能暴露身份 |

## tempo 节奏类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 快节奏 | 短句连发，紧迫感 | 战斗、争吵、紧张 |
| 慢节奏 | 长句、停顿、思考感 | 回忆、深情、哲理 |
| 顿挫 | 快慢交替，有节奏感 | 日常对话、吐槽 |
| 平稳 | 不快不慢，稳定 | 叙述、解释、汇报 |

## register 语域类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 正式 | 书面语、敬语 | 公务、谈判、演讲 |
| 随意 | 口语、俚语 | 朋友聊天、日常 |
| 专业 | 行业术语 | 技术讨论、战斗指挥 |
| 混搭 | 正式+随意交替 | 反差萌、幽默 |


# ════════════════════════════════════════════════════════════
#  四、必填 vs 选填
# ════════════════════════════════════════════════════════════

## 必填字段（所有角色必须有）
  name, signature_style, catchphrases, forbidden_patterns,
  example_lines

## 选填字段（有则填，没有写"无"）
  constraints, vocabulary_level, emotional_range,
  growth_notes, tempo, register, tone

# ─────────────────────────────────────
# 示例1：报价式吐槽（沈浮）
# ─────────────────────────────────────

[沈浮]
signature_style: 报价式吐槽，万物可折成票价。嘴贫但不油滑，贫是铠甲，关键场合收短句。
catchphrases: 票价, 入园, 营业, 老板, 开张
forbidden_patterns: 不许油滑，不许长篇大论，不许文绉绉
constraints:
  - "提爷爷就闭嘴，转去巡园"
  - "真正重要的话说得很短、很直"
vocabulary_level: 报价式（万物可折成票价/成本）
emotional_range: 表面松弛底层焦虑，嘴贫掩盖认真
growth_notes: "无明显变化，始终是报价式吐槽"
example_lines:
  - "八百万的账，你算算，得卖多少张门票？"
  - "乐园不打烊。"
  - "这玩意儿值一张儿童票。"
tempo: 快节奏短句
register: 随意（朋友间）/ 正式（谈判时）
tone: 报价式调侃

# ─────────────────────────────────────
# 示例2：播报体（乐园中枢）
# ─────────────────────────────────────

[乐园中枢]
signature_style: 播报体，开头"叮！"，附注毒舌。金牌客服人格：营业腔、专业、嘴毒。
catchphrases: 叮, 营业中断, 亲爱的游客, 本中枢/俺, 检票
forbidden_patterns: 不许温柔，不许道歉（坦白前），不许暴露身份（坦白前）
constraints:
  - "自称演变：本中枢→俺（839起）"
  - "坦白前：任何隐瞒不许被识破"
  - "毒舌但不恶毒，底线是为游客好"
vocabulary_level: 营业腔（专业+毒舌）
emotional_range: 营业状态为主，偶尔真情流露
growth_notes: "839起自称从'本中枢'变'俺'，从程序到家人"
example_lines:
  - "叮！亲爱的游客，您当前的快乐指数不足以启动该设施，请充值。"
  - "本中枢拒绝评论您的智商。"
  - "俺觉得你在想屁吃。"
tempo: 播报节奏（叮！+正文+附注）
register: 正式（播报）/ 随意（毒舌附注）
tone: 专业+毒舌

# ─────────────────────────────────────
# 示例3：短句大嗓门（大嘴三姆）
# ─────────────────────────────────────

[大嘴三姆]
signature_style: 短句大嗓门，平时更憨，战时下令像换人。觉醒后文武分明。
catchphrases: 俺, 饿, 中, 开饭, 园长
forbidden_patterns: 不许文绉绉，不许长篇大论，不许细腻抒情
constraints:
  - "战时下令要换人：短促、精准、不容置疑"
  - "觉醒后文武分明：平时憨，战时狠"
vocabulary_level: 极简（饿/中/开饭）
emotional_range: 开朗直白，饿了就喊
growth_notes: "179-180三星觉醒后，战时语言变精准"
example_lines:
  - "俺饿了。"
  - "中！"
  - "园长，有人来砸场子。"
tempo: 快节奏
register: 随意（日常）/ 正式（战时下令）
tone: 憨直（日常）/ 威严（战时）

# ─────────────────────────────────────
# 示例4：公文腔（程霜）
# ─────────────────────────────────────

[程霜]
signature_style: 公文腔转日常的反差萌。白天写报告，晚上偷刷滑道。说话严谨但偶尔露怯。
catchphrases: 查封, 合规, 报告, 审批, 通商
forbidden_patterns: 不许粗俗，不许完全放松（始终保持一定严谨）
constraints:
  - "公文腔是底色，日常时可以放松但不会完全消失"
  - "偶尔露怯是反差萌的关键"
vocabulary_level: 公文式（书面语+专业术语）
emotional_range: 克制专业，偶尔露怯
growth_notes: "从巡查使到盟主，公文腔逐渐融入更多温度"
example_lines:
  - "根据义盟第XX条，你们的造浪池需要重新审批。"
  - "……我就刷一次，不算违规吧？"
  - "通商协议我拟好了，你看看。"
tempo: 稳定偏慢
register: 正式（公务）/ 随意（私下，但仍有公文腔底色）
tone: 严谨+偶尔露怯

# ─────────────────────────────────────
# 示例5：文士腔（敖涸）
# ─────────────────────────────────────

[敖涸]
signature_style: 文士形态，账房逻辑。立场错逻辑通，说话像账房先生不带情绪。
catchphrases: 火候, 记账, 朕, 起锅, 三千年前
forbidden_patterns: 不许情绪化，不许脸谱化反派腔
constraints:
  - "立场错逻辑通：他说的每句话在他的逻辑里都成立"
  - "不带情绪：像在做账，不像在吵架"
vocabulary_level: 文士腔（古风+账房术语）
emotional_range: 冷静克制，像在做账
growth_notes: "无明显变化，始终冷静"
example_lines:
  - "水要回来这件事，朕比你们都早知道三千年。"
  - "火候到了，就得起锅。"
  - "朕的，到了。"
tempo: 顿挫有致
register: 正式（古风）
tone: 冷静+账房逻辑

# ─────────────────────────────────────
# 示例6：冷面精准（雾隐千黛）
# ─────────────────────────────────────

[雾隐千黛]
signature_style: 冷面不许无情。情感全走动作线（门口留伞）。话少但精准。
catchphrases: 巡逻, 交接, 案卷, 门口, 伞
forbidden_patterns: 不许话多，不许直接表达情感，不许撒娇
constraints:
  - "情感走动作线：门口留伞>说出来"
  - "话少但精准：每句话都有信息量"
vocabulary_level: 精准（少而精）
emotional_range: 冷面为主，偶尔通过动作流露
growth_notes: "无明显变化，始终冷面精准"
example_lines:
  - "夜班，门口伞给你留了。"
  - "案子结了。"
  - "……嗯。"
tempo: 慢节奏，话少
register: 正式（公务）/ 随意（极简）
tone: 冷面+温情（通过动作）

# ─────────────────────────────────────
# 示例7：较真腔（姗姗）
# ─────────────────────────────────────

[姗姗]
signature_style: 较真到底。不是鱼尾萌，是较真萌。认死理，一步不让。
catchphrases: 敕令, 赝账, 交印, 族里, 较真
forbidden_patterns: 不许含糊，不许差不多就行，不许萌混过关
constraints:
  - "较真是底色：任何含糊都要纠正"
  - "不是鱼尾萌：是认真到让人头疼"
vocabulary_level: 精准（账务/敕令术语）
emotional_range: 较真为主，偶尔无奈
growth_notes: "无明显变化，始终较真"
example_lines:
  - "这道敕令是假的。"
  - "印我交，人我不交。"
  - "账要算清楚。"
tempo: 稳定偏慢
register: 正式（公务）/ 随意（较真时）
tone: 较真+无奈

# ─────────────────────────────────────
# 示例8：海盗腔（霍青澜）

forbidden_patterns: 不许文绉绉，不许绕弯，不许含蓄

emotional_range: 豪爽直接，不掩饰
growth_notes: "从海盗到将军，说话方式不变，内容变"
example_lines:
  - "图什么？"
  - "这笔买卖，划算。"
  - "缴械不杀，投降从宽。"
tempo: 快节奏
register: 随意（海盗腔）
tone: 豪爽+直接

# ─────────────────────────────────────
# 示例9：科学腔（公输瑶）
# ─────────────────────────────────────

[公输瑶]
signature_style: 科学腔转信仰崩塌。"它不是机器"用职业生命挡刀。
catchphrases: 数据, 检测, 伪科学, 手记, 它不是机器
forbidden_patterns: 不许感性（前期），不许放弃科学（始终）
constraints:
  - "科学腔是底色：即使信仰崩塌也用数据说话"
  - "'它不是机器'是最高级别的认真"
vocabulary_level: 科学术语（检测/数据/伪科学）
emotional_range: 从纯科学到科学+信仰
growth_notes: "从'这不科学'到'它不是机器'：科学腔融入信仰"
example_lines:
  - "检测报告显示……这不科学。"
  - "它不是机器！"
  - "数据不会说谎，但数据可能被投毒。"
tempo: 稳定
register: 正式（科学报告）
tone: 科学+信仰崩塌

# ─────────────────────────────────────

example_lines:
  - "……好吃的。"
  - "空白页。"
  - "我保他。"
tempo: 慢节奏
register: 随意（极简）

# 示例12：相声腔（小丑贾克）

[小丑贾克]

growth_notes: "无明显变化，始终是节目"
