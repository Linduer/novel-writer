#  一、字段分级（对应三级约束体系）
# ════════════════════════════════════════════════════════════

能力体系分两层：
  1. 能力体系（静态）— 定义规则，Tier1不可改
  2. 角色能力状态（动态）— 实时记录，随章节更新

两层分开设计的原因：
  - 能力体系是世界观设定，写死不改
  - 角色能力状态是剧情推进的结果，每章都可能变

能力体系大部分是硬设定，属于 Tier1 基础约束。

## 第一档：基础性（绝对不可偏离）— Tier1

一旦写定永远不改，写入 Tier1 基础约束。

  境界体系               境界等级名称和定义
  境界突破节点           每个角色的突破章节（写死）
  天赋类型               天赋名称和效果
  设施对应神通           设施=神通的对应关系
  五钥名称和获取方式     五钥是什么、怎么获得
  打捞规则               光色含义、概率规则
  英灵规则               英灵定义、薪资、觉醒规则
  信仰值定义             什么是信仰值、怎么获取
  能力上限               每个角色的能力天花板
  致命弱点               每个能力的致命缺陷
  禁忌规则               绝对不能做的事

## 第二档：可演变（随剧情自然变化）— Tier2

会随剧情发展而变化。

  角色当前境界           实际境界（随突破变化）
  设施解锁进度           哪些设施已解锁
  五钥收集进度           已收集几把钥匙
  信仰值存量             当前有多少信仰值
  英灵编制               当前队伍组成
  军团规模               军团人数变化
  技能熟练度             技能使用次数越多越强
  装备强化等级           装备强化进度

## 第三档：可偏离（根据行文情况调整）— Tier3

每章可灵活调整。

  战斗描写               具体战斗方式
  设施使用细节           具体怎么用设施
  技能组合               多个技能的组合方式
  战斗策略               具体战术选择


# ════════════════════════════════════════════════════════════
#  二、战斗平衡系统（防崩必备）
# ════════════════════════════════════════════════════════════

写能力体系最怕的就是"战力崩坏"。必须提前设计好平衡机制。

## 2.1 成长曲线

每个角色的成长必须有明确的曲线，不能无限变强。

### 成长曲线类型

| 类型 | 说明 | 适用角色 | 示例 |
|------|------|----------|------|
| 线性 | 匀速成长 | 配角、工具人 | 普通英灵 |
| 指数 | 前期慢后期快 | 主角、核心配角 | 沈浮 |
| 阶梯 | 突破后暴涨，平台期平稳 | 修仙类角色 | 境界突破 |
| 饱和 | 接近上限后变慢 | 天花板明确的角色 | 三姆 |
| 衰退 | 先强后弱 | 悲剧角色、反派 | 敖涸 |

### 成长阶段划分

| 阶段 | 说明 | 占全书比例 |
|------|------|-----------|
| 蛰伏期 | 基础能力，频繁受挫 | 前20% |
| 成长期 | 能力解锁，开始反杀 | 20%-50% |
| 爆发期 | 核心能力全开，连续高潮 | 50%-80% |
| 收束期 | 能力封顶，回归初心 | 最后20% |

## 2.2 制衡机制

每个强能力必须有对应的制衡，否则会崩。

### 制衡类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 资源制衡 | 使用需要消耗资源 | 技能烧信仰值 |
| 时间制衡 | 有冷却时间/蓄力时间 | 大招需要蓄力3秒 |
| 条件制衡 | 特定条件下才能使用 | 只能在满月使用 |
| 反噬制衡 | 使用后有负面效果 | 使用后昏迷三天 |
| 克制制衡 | 被特定能力克制 | 火系被水系克制 |
| 数量制衡 | 同时使用数量有限 | 同时只能召唤3只 |
| 范围制衡 | 影响范围有限 | 只能单体攻击 |
| 副作用制衡 | 使用有副作用 | 每次使用减少寿命 |

### 制衡设计原则

1. **能力越强，制衡越大**：原子弹很强，但需要核弹头+发射井+维护成本
2. **制衡要有意义**：不能是"很强但有个没用的弱点"
3. **制衡要可被克服**：通过成长/道具/策略可以绕过制衡
4. **制衡要一致**：不能今天有制衡明天就没了

## 2.3 克制关系

设计清晰的克制链，让战斗有策略性。

### 克制链模板

```
A 克制 B
B 克制 C
C 克制 A

或者：
A 克制 B
B 克制 C
C 克制 D
D 克制 A
```

### 克制效果

| 效果 | 说明 | 示例 |
|------|------|------|
| 伤害加成 | 克制方伤害+50% | 火克木 |
| 伤害减免 | 被克制方伤害-50% | 木被火克 |
| 控制效果 | 克制方可附加控制 | 冰克火，冻结 |
| 技能封印 | 被克制方无法使用特定技能 | 水克火，火系技能失效 |

## 2.4 战力天花板

每个角色必须有明确的天花板，防止无限变强。

### 天花板类型

| 类型 | 说明 | 适用角色 |
|------|------|----------|
| 境界天花板 | 境界到顶无法突破 | 普通修士 |
| 天赋天花板 | 天赋限制了上限 | 天赋型角色 |
| 寿元天花板 | 寿命限制 | 非永生角色 |
| 代价天花板 | 变强需要付出代价 | 交易型能力 |
| 剧情天花板 | 剧情需要他到此为止 | 配角、反派 |

### 主角天花板设计

主角不能无限变强，必须有明确的天花板：

```
# 示例：沈浮的能力天花板
天花板: "羁绊位，不是战斗位"
说明: "光环下全队战力翻倍，但自己不亲自下场"
约束: "不许写成武力超人"
原因: "主角的价值是运营乐园，不是打架"
```

## 2.5 战力对标表

建立清晰的战力对标，让读者有直观感受。

### 对标格式

```
# 战力对标表
# 以"一星英灵"为基准单位

基准: 一星英灵 = 1

角色战力:
  沈浮: 0.5（光环下0，光环外0.5）
  三姆: 3（一星）→ 8（三星）
  蓝博: 2（一星）→ 6（三星）
  千黛: 1.5（一星）→ 5（三星）
  敖涸: 10（沧海境）
  沧溟: 50（归墟境）
  渊: 100+（水位本身）

设施战力:
  儿童戏水池: 0.5
  造浪池: 5
  大喇叭: 8
  海啸池: 20（需要全域同声）

克制关系:
  水系 → 火系（+50%）
  火系 → 木系（+50%）
  木系 → 土系（+50%）
  土系 → 水系（+50%）
```


# ════════════════════════════════════════════════════════════
#  三、限制系统（能力不能无限制使用）
# ════════════════════════════════════════════════════════════

每个能力都必须有使用限制，否则就没有紧张感。

## 3.1 限制类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 资源限制 | 需要消耗资源 | 信仰值、 mana、体力 |
| 冷却限制 | 使用后需要冷却 | 大招CD 60秒 |
| 条件限制 | 特定条件下才能使用 | 只能在水中使用 |
| 范围限制 | 影响范围有限 | 只能攻击前方扇形 |
| 数量限制 | 同时使用数量有限 | 同时只能召唤3只 |
| 时机限制 | 特定时机才能使用 | 只能在满月使用 |
| 代价限制 | 使用有代价 | 每次减少1年寿命 |
| 禁忌限制 | 绝对不能对某人/某事使用 | 不能对队友使用 |

## 3.2 限制设计原则

1. **能力越强，限制越大**
2. **限制要有意义**：不是摆设，是真正的制约
3. **限制可以被克服**：通过成长/道具/策略
4. **限制要一致**：不能今天有限制明天就没了

## 3.3 限制表示例

```
# 能力限制表
能力: 造浪池（主炮）
限制:
  - 资源: 需要消耗信仰值（每秒100点）
  - 条件: 需要游客尖叫装填
  - 范围: 只能攻击前方扇形
  - 冷却: 使用后需要30秒冷却
  - 代价: 每次使用消耗乐园3个月流水

能力: 羁绊光环
限制:
  - 范围: 只对直属队员有效
  - 条件: 需要沈浮在场
  - 副作用: 沈浮本人不参战
  - 禁忌: 不能叠加其他光环

能力: 打捞天赋
限制:
  - 条件: 需要在水中使用
  - 范围: 只能打捞一定深度
  - 冷却: 每天只能使用3次
  - 代价: 满潮夜危险翻倍
```

#  四、角色能力成长表
# ════════════════════════════════════════════════════════════

每个重要角色必须有明确的能力成长表。

## 4.1 成长表格式

```
# 角色能力成长表
角色: 沈浮
天花板: 羁绊位（不是战斗位）

成长曲线: 指数型
  蛰伏期（ch001-200）:
    境界: 滴水境
    能力: 打捞天赋、羁绊光环
    战力: 0.5
    说明: "开局一块木筏，靠光环加成队友"

  成长期（ch201-500）:
    境界: 溪流境→江河境（ch402）
    能力: 解锁造浪池、大喇叭
    战力: 1
    说明: "乐园做大，开始有反击能力"

  爆发期（ch501-800）:
    境界: 湖泽境（ch555）
    能力: 解锁全部设施
    战力: 2

    境界: 湖泽境（封顶）
    能力: 全设施
    战力: 2（不变）
    说明: "回归初心，免票开业"
```

#  五、字段说明
# ════════════════════════════════════════════════════════════

## 境界体系
- 境界:                等级名称和定义（按顺序排列）
- 突破节点:            每个角色的突破章节（写死不可改）

## 天赋体系
- 天赋:                天赋名称、持有者、效果、特殊规则
- 天赋类型:            innate（先天）vs acquired（后天）

## 设施体系
- 设施:                设施名称、对应神通、首秀章节、特殊规则
- 设施解锁条件:        什么条件下解锁

## 打捞系统
- 打捞规则:            光色含义、概率规则、成长方式

## 英灵系统
- 英灵:                定义、获取方式、薪资、觉醒规则
- 编制:                队伍组成规则

## 信仰值系统
- 信仰值:              定义、来源、消耗、深层设定

## 五钥体系
- 五钥:                五钥名称、获取方式、集齐效果

## 战斗平衡
- 战力对标:            以基准单位衡量各角色/设施战力
- 克制关系:            属性克制链
- 成长曲线:            每个角色的成长轨迹
- 制衡机制:            能力的使用限制

## 限制系统
- 能力限制:            每个能力的使用限制
- 禁忌规则:            绝对不能做的事
- 致命弱点:            每个角色的致命缺陷
