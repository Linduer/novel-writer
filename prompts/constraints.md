# 约束体系说明

本系统使用三级约束体系，按**稳定性**分级。冲突时高档约束优先。

## 约束等级

### 第一档：基础性（TIER_1_FOUNDATION）— 绝对不可偏离

**永久不变的内容**，一旦写定永远不可修改：

| 分类 | 说明 | 示例 |
|------|------|------|
| 角色 | 角色名、核心性格 | 林远嘴碎但善良 |
| 世界观 | 硬规则、能力体系 | 境界体系不可修改 |
| 风格 | 行文底线 | 禁止AI味句式 |
| 平台 | 硬性要求 | 每章1000-2500字 |
| 格式 | 输出规范 | 对话用引号 |

> 这是写作的"宪法"，任何情况下都不可违反。

### 第二档：可演变（TIER_2_EVOLVABLE）— 随行文自然变化

**会随剧情发展而变化的内容**：

| 分类 | 说明 | 变化方式 |
|------|------|----------|
| 关系 | 角色间关系 | 敌对→合作→暧昧→夫妻 |
| 情绪 | 角色当前情绪 | 愤怒→平静→感动 |
| 状态 | 角色状态 | 受伤→痊愈→更强 |
| 伏笔 | 伏笔状态 | 活跃→已回收 |
| 情节 | 大纲情节走向 | 可调整但需有意识修改 |

> 这些约束会随章节推进**自动更新**。例如：
> - 第1章：林远叫系统"系统"
> - 第50章：林远叫系统"老伙计"（关系更亲近了）
> - 系统自动将"系统"更新为"老伙计"

### 第三档：可偏离（TIER_3_FLEXIBLE）— 根据行文情况调整

**每章可灵活调整的内容**：

| 分类 | 说明 | 灵活度 |
|------|------|--------|
| 细纲 | 本章场景设计 | 可调整场景顺序 |
| 节奏 | 张弛安排 | 可加速/减速 |
| 对话 | 具体对话内容 | 可偏离细纲 |

> 细纲是参考，不是枷锁。可以根据行文情况灵活偏离。

## 冲突解决规则

```
当不同档次的约束发生冲突时：
  第一档（基础性）> 第二档（可演变）> 第三档（可偏离）

示例：
  Tier1 说"林远性格不变"
  Tier2 说"林远此刻愤怒"
  Tier3 说"林远要冷静分析"
  
  → Tier2的情绪描写服从Tier1的性格设定
  → Tier3的节奏安排服从Tier1和Tier2
```

## 自动维护流程

```
项目初始化  → 写入Tier1预置基础约束（行文底线、风格规则）
大纲导入    → 写入Tier2大纲情节约束
write生成   → 写入Tier3当章细纲
save保存    → 同步Tier2（从记忆提取关系/情绪变化）+ 归档Tier3
```

## 存储结构

```
constraints/
  tier1_foundation.json   ← 基础约束（极少变动，手动补充）
  tier2_evolvable.json    ← 可演变约束（随章节自动更新）
  tier3_flexible.json     ← 可偏离约束（每章覆盖）
  archive/
    ch001.json            ← 归档的第1章细纲
    ch002.json            ← 归档的第2章细纲
```
