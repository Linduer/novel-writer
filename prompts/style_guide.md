# 行文风格约束指南

> 本指南基于2026年多平台反AI写作治理数据、283万字语料库研究（lieflat-less-ai-tone）、
> StoryScope叙事特征研究（马里兰大学+Google DeepMind）、番茄/起点/晋江平台编辑审稿经验，
> 以及大量网文作者和读者反馈整理而成。
>
> **用途**：作为提示词的一部分注入LLM，约束生成文本的行文风格，避免"AI味"。
> **维护**：本文件末尾留有"人工补充区"，作者可自行添加个人风格约束。

---

## 一、核心原则

1. **具体胜过抽象** — 写"他手抖了"，不写"他感到紧张"
2. **不完美胜过工整** — 允许句式参差、段落长短不一
3. **潜台词胜过直白** — 角色不会把心里话全说出来
4. **场景胜过说明** — 世界观通过冲突和细节透出，不用大段交代

---

## 二、对话写法（重点约束）

### 禁止：对话分割不自然

**问题描述**：AI喜欢把一段完整的对话拆成两半，中间插入动作描写或环境描写，导致对话节奏断裂。读者读起来感觉角色说话总被打断，像是在看话剧而不是小说。

**典型错误示范**：
```
"园长。"中枢的声音在干活的间隙里飘过来，"鉴于物品信息已更新，本中枢有一项运营建议。"
"是你认得它。"沈浮说，"不是它反光。"
```

**正确写法**：
- 短对话（一句话能说完的）不要拆开，让角色一口气说完
- 动作描写放在对话之前或之后，不要插在对话中间
- 如果必须在对话中插入描写，只在对话的自然停顿处插入

**规则**：
- 一轮对话（一个角色说的一段话）中间最多插入1次描写，且必须在语义完整处
- 两个角色的对话之间，不要每次都加描写，保持对话的来回节奏
- 角色说短句（3-5个字）时，不要在中间插入任何东西

### 禁止：对话过于书面化

**问题描述**：AI生成的对话像在念课文，用词太正式，句式太完整，缺少口语感。

**规则**：
- 对话要像"人说话"，不是"文章"
- 加入语气词："啊""嘛""呢""吧""得了""行""那啥"
- 允许角色说半句话："如果你当时不——算了，不说了。"
- 允许打断："你听我说——""我不听。"
- 允许重复："不是，我的意思是……不是你想的那样。"
- 检验标准：写完对话后，想象你身边的人会不会这么说话。如果不会，就改。

### 禁止：所有角色说话风格雷同

**规则**：
- 粗人说粗话，书生咬文嚼字
- 每个角色有3-5个常用词/口头禅
- 急性子用短句（3-5字往外蹦），慢性子可以用长句
- 地位低的人说话带敬语或犹豫，地位高的人说话直接或命令式

### 禁止：对话缺少潜台词

**规则**：
- 角色嘴上说的和心里想的应该不一样
- 写"没事"时，手上应该攥紧了拳头
- 写"随便"时，语气应该是冷的
- 不要让角色直接说出自己的感受，让读者自己去体会

## 三、描写写法

### 禁止：过度身体反应描写

**问题描述**：AI对"展示感受"执行得过于认真。81%的情况下AI会通过身体反应表达情绪，而且特别八股——写恐惧时胸口收紧、冷汗渗出、拳头握紧、灯光变暗。人类更可能直接写"他害怕了"。

**规则**：
- 不是每种情绪都需要身体反应描写
- 可以直接写情绪："他害怕了""她气得不行"
- 如果要用身体反应，不要用"标准套餐"（冷汗、心跳加速、拳头握紧）
- 换成具体的、不标准的反应："他开始抠指甲""她一直在揉衣角"

### 禁止：感官描写过载

**规则**：
- 一场戏里调动2-3种感官就够了，不要五感全上
- 重点场景值得花笔墨，日常推进只需1-2个感官细节点缀
- 过度描写会拖慢节奏

### 禁止：环境描写八股化

**典型AI环境描写**：
```
夕阳的余晖洒在大地上，金色的光芒为一切都镀上了一层温暖的色彩。
空气中弥漫着淡淡的花香，微风轻拂过脸颊，带来一丝凉意。
```

**规则**：
- 不要写"夕阳的余晖洒在大地上"这类套话
- 环境描写要和角色情绪、剧情相关，不要为写景而写景
- 用具体物件代替全景："路边摊冒出的白色蒸汽""墙皮脱落露出的红砖"
- 环境描写要为情节服务：安静场景里突然出现异响，嘈杂环境里突然安静

### 禁止：心理活动直给

**问题描述**：AI写"他心里涌起一股莫名的情绪"或"她感到一阵悲伤"，等于替读者把感受做完了。

**规则**：
- 少用形容词定义情绪，多用动作和生理反应外化情绪
- 与其写"她很紧张"，不如写"她的手指在桌下绞在一起，指甲掐进掌心"
- 好的心理描写不超过2-3句，紧接着就被一个动作或对话打断
- 直接写"他很难过""她非常生气"是可以的，不要每段都用身体反应

## 四、句式与节奏

### 禁止：句式过于工整对称

**问题描述**：大量排比、对仗句式，句子长短高度趋同。真人写稿会长短句交错，AI容易写得每一段、每一句长度都差不多。

**规则**：
- 长短句交错：不要连续3句以上都是相同长度的句子
- 穿插超短句（3-6个字）："他懂了。""来不及了。""算了。""行。"
- 不要每段都是"总分总"结构
- 不要用"首先……其次……最后"这种机械连接
- 不要用"值得注意的是""综上所述""从多个维度来看"等套话

### 禁止：冒号引出空转列表

**问题描述**：AI先写一句没有信息的套话冒号，紧接着排出一串列表项。频率是人类的9.4倍。

**典型错误**：
```
本章涉及以下几个方面：
1. 角色状态
2. 伏笔管理
3. 世界观设定
```

**规则**：
- 不要在小说正文里用列表格式
- 不要用冒号引出一串并列内容
- 把列表内容融入叙事中

### 禁止：对举结构滥用

**问题描述**：AI喜欢在没有矛盾的地方强行制造虚假对立。"不是A而是B"句式频率是人类的3.4倍。

**规则**：
- 不要用"不是……而是……"句式，除非确实存在对比关系
- 不要在每段结尾都来一句总结式的对举
- 用更自然的表达："比起A，B更……""与其说A，不如说B"也不要频繁使用

### 禁止：段首零回指评论

**问题描述**：新段落开头直接写评价，省略了代词，导致上下文指代断裂。频率是人类的4.4倍。

**典型错误**：
```
听起来像一条功能描述。
值得注意的是，这个设定非常巧妙。
```

**规则**：
- 新段落开头要有明确的主语，不要让读者猜"谁""什么"
- 不要在段首写"值得注意的是""需要说明的是""有趣的是"等零回指评论
- 恢复自然的篇章衔接

## 五、叙事结构

### 禁止：叙述者替读者总结主题

**问题描述**：AI叙述者有77%的概率亲自解释主题，人类作品为52%。AI生怕读者读不懂，总要出来总结"这个故事告诉我们……"。

**规则**：
- 不要让叙述者直接点明主题
- 不要在结尾写"他终于明白了……""这个故事告诉我们……"
- 让读者自己去体会故事的含义
- 角色经历事件后，不要替他总结"学到了什么"

### 禁止：情节过于单线

**问题描述**：79%的AI故事没有支线，人类作品为57%。AI反而更愿意把故事弄乱一点，使用更多倒叙、插叙和时间跳跃。

**规则**：
- 允许适当的支线，不必每章都推进主线
- 允许倒叙、插叙
- 不要让所有事情都解释清楚，允许留下一些模糊空间
- 可以让角色做出一些"没啥意义"的决定，不必每个决定都是关键抉择

### 禁止：结局过度包饺子

**问题描述**：69%的AI故事里，模型喜欢让主角做出一个明确决定，并让这个决定成为故事闭环的钥匙。人类作品中这一比例为46%。

**规则**：
- 不是每个冲突都需要完美解决
- 允许偶然、他人和环境共同左右结果
- 不要让主角每次都做出"正确"的决定
- 可以让一些事情悬而未决

### 禁止：对话中讨论人生道理

**问题描述**：AI故事里的对话出现哲学讨论的比例是59%，而人类只有34%。角色不应该在对话中大段讨论人生哲理。

**规则**：
- 角色对话应该围绕具体事情，不要借角色之口讲大道理
- 不要在对话中插入哲学讨论
- 如果角色要表达观点，用行动而不是说教

## 六、标点符号

### 禁止：破折号过密

**规则**：
- 一个段落内最多出现1次破折号
- 不要用破折号打断对话的自然节奏
- 用省略号代替部分破折号："你听我说——"→"你听我说……"

### 禁止：冒号用于对话标注

**规则**：
- 对话用引号，不要用冒号
- 不要用"XX说："这种格式，用"XX说，"或"XX道，"

### 允许：适当使用问号和感叹号

**规则**：
- 可以用设问句制造对话感（人类设问句频率是AI的17倍）
- 不要滥用感叹号，一章内不超过5个
- 问号可以频繁使用，制造口语感

---

## 七、番茄小说平台特定要求

### 节奏要求
- 每章1000-2500字
- 每章至少1个爽点+1个章尾钩子
- 每3章一个小高潮，每10章一个大高潮
- 爽点间隔不超过3章

### 开局要求
- 前3章必须亮出金手指或核心悬念
- 切忌长篇大论铺垫世界观
- 世界观通过人物冲突和场景细节透出来，禁止大段背景交代

### 对话要求
- 对话要爽、要快，每轮对话不超过3句就必须有反转或情绪爆发
- 长对话直接劝退读者
- 用动作锚定说话人，不要用"XX说"

---

## 八、自查清单

写完每一章后，检查以下项目：

- [ ] 对话是否像"人说话"？有没有过于书面化？
- [ ] 一段对话中间是否被拆开？拆开的位置是否自然？
- [ ] 所有角色的说话风格是否区分开了？
- [ ] 有没有"不是A而是B"句式？
- [ ] 有没有"值得注意的是""综上所述"等套话？
- [ ] 有没有冒号引出的列表？
- [ ] 每段开头是否有明确主语？
- [ ] 情绪描写是否用了"标准套餐"（冷汗、心跳加速）？
- [ ] 环境描写是否为写景而写景？
- [ ] 有没有让叙述者直接总结主题？
- [ ] 结尾是否替读者总结了"道理"？
- [ ] 句式是否过于工整？长短句是否交错？
- [ ] 破折号是否过密？
- [ ] 章尾是否有钩子？
